# CUBES 2048.io 复刻版

学习 [crazygames.com/game/cubes-2048-io](https://www.crazygames.com/game/cubes-2048-io) 玩法后 1:1 复刻，并改造为**手机横屏游戏**：

- **右手**：右下虚拟摇杆控制方向
- **左手**：左下技能按钮释放技能

## 原版玩法还原

- 立方体蛇 × 2048 合并：吃相同数字的块合并升级（2→4→8→…→2048）
- 吞人规则：头部数字大于敌人即可吞掉对方整条链；可切入敌人尾部抢夺小块
- 加速：按住 2 秒极速、6 秒冷却，期间消耗尾部最小方块（与原版一致）
- ÷ 陷阱：碰到后全身数字减半（原版要素）
- ⚡ 加速球：刷新加速冷却（原版要素）
- 实时排行榜、小地图、AI 敌人（18 个，会觅食/追击/逃逸/用技能）

## 技能系统

| 技能 | 获取方式 | 效果 |
| --- | --- | --- |
| 加速（固定） |  always | 按住极速 2 秒，冷却 6 秒 |
| 闪身步 | 吃掉 » 技能块 | 瞬间冲刺，迅速躲避迎面而来的敌人，冲刺瞬间免伤 |
| 隐身 | 吃掉 眼 技能块 | 短暂消失 3.5 秒，期间无法攻击敌人 |
| 烧心 | 吃掉 火焰 技能块 | 抛出烧心，被击中的敌人分数减半 |

技能块每吞一个 +1 次使用次数（上限 3）。

## 运行

纯静态页面，无依赖无构建：

```bash
# 本地
python3 -m http.server 8000
# 打开 http://localhost:8000

# 部署
GitHub Pages: https://niuontheway-ops.github.io/cubes-2048-io/
```

桌面端调试：鼠标转向 / 按住左键或空格加速 / 1、2、3 释放闪身步、隐身、烧心。

## 技术

- 单页 Canvas 2D 游戏，模块化 JS（config / audio / world / bots / render / ui / main）
- WebAudio 实时合成音效（吃块、合并升调、吞人、死亡、加速轰鸣、冲刺、隐身、烧心爆炸等）与轻量背景音乐
- 音效为按原版风格实时合成，非原版音频文件
